# 09 · Срочно отозвать токен

Когда: токен попал в чат, документ, скриншот, репозиторий или к постороннему. Сначала отзыв, потом новый токен (04).
Агент подставляет: `{{BUSINESS_NAME}}`, `{{SYSTEM_USER_NAME}}`, `{{APP_NAME}}`.

```text
{{RULES}}

Задача — отозвать все токены системного пользователя «{{SYSTEM_USER_NAME}}» для приложения «{{APP_NAME}}».

1. Открой https://business.facebook.com/settings → «{{BUSINESS_NAME}}» → Пользователи → Системные пользователи →
   «{{SYSTEM_USER_NAME}}».
2. «Отозвать маркеры» (Revoke tokens) → выбери приложение «{{APP_NAME}}» → подтверди.
3. Сам пользователь, его активы и приложение остаются — ничего не удаляй.

В ответе: отозваны ли маркеры. Дальше — промпт 04, шаги 4–5 (новый маркер).
```

После отзыва старый токен перестаёт работать сразу; `doctor.py` покажет «токен не принят Meta», пока не сохранён новый.

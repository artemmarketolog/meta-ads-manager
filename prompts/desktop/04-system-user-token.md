# 04 · Системный пользователь и токен

Когда: приложение создано (03). Системный пользователь — «робот» бизнес-портфолио: его токен бессрочный и не
слетает, когда вы меняете пароль или выходите из Facebook.
Агент подставляет: `{{BUSINESS_NAME}}`, `{{APP_NAME}}`, `{{APP_ID}}`, `{{SYSTEM_USER_NAME}}` (например «Claude Ads»),
`{{AD_ACCOUNTS}}` (список «название — act_…»), `{{PAGES}}`, `{{PERMISSIONS}}` (из references/permissions.md).

```text
{{RULES}}

Задача — создать системного пользователя, дать ему доступ к рекламе и выпустить токен для моего Claude Code.

1. Открой https://business.facebook.com/settings → портфолио «{{BUSINESS_NAME}}» → Пользователи → Системные пользователи
   (Users → System users). Если «{{SYSTEM_USER_NAME}}» уже есть — используй его. Иначе «Добавить»:
   имя «{{SYSTEM_USER_NAME}}», роль «Администратор» (Admin).
2. «Назначить активы» (Assign assets) этому пользователю:
   - Приложения: «{{APP_NAME}}» ({{APP_ID}}) — полный доступ / управление приложением;
   - Рекламные аккаунты — «Управление кампаниями» (Manage campaigns) и «Просмотр эффективности»:
     {{AD_ACCOUNTS}}
   - Страницы — полный доступ (минимум: Реклама, Статистика, Контент):
     {{PAGES}}
   - Пиксели (наборы данных) этих кабинетов — «Управление» / «Использование»;
   - Аккаунты Instagram и WhatsApp, если есть, — полный доступ.
   Выпиши, какие активы назначить не удалось и почему (например, их нет в портфолио).
3. Если приложение не появилось у пользователя — Аккаунты → Приложения → «{{APP_NAME}}» → «Назначить людей»
   (Assign people) → «{{SYSTEM_USER_NAME}}» → полный доступ.
4. У «{{SYSTEM_USER_NAME}}» нажми «Создать маркер» (Generate new token):
   - приложение «{{APP_NAME}}»;
   - срок действия: «Никогда» (Never);
   - разрешения — отметь ровно эти: {{PERMISSIONS}}
     (если какого-то нет в списке — выпиши его название, остальные отметь);
   - «Создать маркер».
5. Токен на экране НЕ пересказывай и никуда не вставляй. Нажми кнопку «Копировать» (Copy) рядом с ним,
   затем «Готово». Напиши мне: «Токен в буфере обмена — скажи Claude Code: токен в буфере».

В ответе: имя и ID системного пользователя, назначенные кабинеты и страницы, неназначенные, какие разрешения
отметить не удалось. Сам токен — нет.
```

После этого ученик говорит своему Claude Code «токен в буфере», и агент запускает
`python3 setup.py token --from-clipboard` — токен проверяется в Meta, сохраняется в `~/.config/meta-ads-manager/meta.env`
(chmod 600), буфер очищается. Если Claude Code работает на другом компьютере (сервер), ученик сам запускает
`python3 setup.py token` в терминале этого сервера и вставляет токен в скрытый ввод.

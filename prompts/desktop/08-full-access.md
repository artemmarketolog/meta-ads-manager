# 08 · Full access для Marketing API

Когда: `doctor.py` пишет «Limited access», а запуски упираются в лимит (~20 изменений за 5 минут на кабинет).
Условие Meta: не меньше 500 вызовов Marketing API за 15 дней и меньше 15% ошибок. Обычная работа — запуски,
`status`, `insights` — набирает это за 1–2 недели. Специально «накручивать» вызовы не нужно.
Агент подставляет: `{{APP_NAME}}`.

```text
{{RULES}}

Задача — перевести приложение «{{APP_NAME}}» на Full access в Marketing API, если Meta уже разрешает.

1. Открой https://developers.facebook.com/apps → «{{APP_NAME}}» → Проверка приложения → Разрешения и функции
   (App Review → Permissions and Features).
2. Найди «Marketing API Access Tier» (раньше — «Ads Management Standard Access»).
3. Если кнопка «+Upgrade» / «Повысить» активна — нажми и пройди шаги (это не заявка на проверку контента).
   Если неактивна — выпиши, что Meta пишет о прогрессе: число вызовов, процент ошибок.
4. Другие разрешения не трогай и ничего больше на проверку не отправляй.

В ответе: какой уровень стал (Limited/Full), или прогресс до условия.
```

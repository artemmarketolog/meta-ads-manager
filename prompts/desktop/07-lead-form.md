# 07 · Лид-форма (мгновенная форма)

Когда: сценарий `lead_form_*`, а готовой формы у страницы нет. Форму удобнее собрать в интерфейсе —
агент потом берёт только её ID.
Агент подставляет: `{{PAGE_NAME}}`, `{{FORM_NAME}}`, `{{FIELDS}}`, `{{QUESTIONS}}`, `{{PRIVACY_URL}}`,
`{{THANKS_TEXT}}`, `{{SITE_OR_WHATSAPP}}`.

```text
{{RULES}}

Задача — создать мгновенную форму для рекламы на странице «{{PAGE_NAME}}».

1. Открой https://business.facebook.com → выбери страницу «{{PAGE_NAME}}» → Все инструменты →
   Мгновенные формы (Instant forms) → «Создать форму».
2. Название «{{FORM_NAME}}», тип «Больше объёма» (More volume).
3. Поля: {{FIELDS}}. Дополнительные вопросы: {{QUESTIONS}}.
4. Политика конфиденциальности: ссылка {{PRIVACY_URL}}.
5. Экран завершения: текст «{{THANKS_TEXT}}», кнопка ведёт на {{SITE_OR_WHATSAPP}}.
6. Нажми «Опубликовать» (Publish) — это публикует только форму, не рекламу.

В ответе: название и ID формы (число; видно в списке форм или в адресе страницы формы).
```

Проверка: `GET /<form_id>?fields=status,name` → `ACTIVE`. ID пишется в `clients.json` → `lead_gen_form_id`.

# 05 · Новый клиент: партнёрский доступ к его кабинету и странице

Когда: появился клиент, чей кабинет и страница живут в его собственном бизнес-портфолио. Кабинет клиента
не переносят к себе: клиент даёт вашему портфолио партнёрский доступ, а вы назначаете активы системному
пользователю. Токен перевыпускать не нужно — новые активы появятся у него сами.

Агент подставляет: `{{CLIENT_NAME}}`, `{{BUSINESS_NAME}}`, `{{BUSINESS_ID}}`, `{{SYSTEM_USER_NAME}}`,
`{{CLIENT_AD_ACCOUNT_ID}}` (если клиент его прислал).

## Часть А — сообщение клиенту (ученик отправляет сам)

```text
Здравствуйте! Чтобы я вёл рекламу в вашем кабинете, дайте, пожалуйста, доступ моему бизнес-портфолио.
Это безопасно: пароли не нужны, доступ можно забрать в любой момент.

1. Откройте business.facebook.com/settings → ваше портфолио.
2. Пользователи → Партнёры → «Добавить» → «Предоставить партнёру доступ к своим активам».
3. Введите ID моего портфолио: {{BUSINESS_ID}} ({{BUSINESS_NAME}}).
4. Отметьте и дайте полный доступ (или «Управление кампаниями» для кабинета):
   — рекламный аккаунт;
   — страницу Facebook;
   — аккаунт Instagram;
   — пиксель / набор данных сайта (если есть).
5. Напишите мне, когда готово, и пришлите ID рекламного аккаунта (act_…).
```

## Часть Б — промпт для Claude Desktop (после ответа клиента)

```text
{{RULES}}

Задача — проверить, что клиент «{{CLIENT_NAME}}» дал доступ, и назначить его активы системному пользователю.

1. Открой https://business.facebook.com/settings → портфолио «{{BUSINESS_NAME}}».
2. Аккаунты → Рекламные аккаунты: найди кабинет клиента {{CLIENT_AD_ACCOUNT_ID}} (помечен как партнёрский).
   Если его нет — «Добавить» → «Запросить доступ к рекламному аккаунту» (Request access) → ID кабинета →
   «Управление кампаниями». Сообщи, что запрос ушёл и клиенту надо его подтвердить; дальше не продолжай.
3. Если кабинет есть — назначь активы клиента пользователю «{{SYSTEM_USER_NAME}}»
   (Пользователи → Системные пользователи → «{{SYSTEM_USER_NAME}}» → «Назначить активы»):
   - рекламный аккаунт — «Управление кампаниями» и «Просмотр эффективности»;
   - страница клиента — полный доступ (минимум Реклама, Статистика, Контент);
   - Instagram клиента и пиксель — полный доступ / управление.
   Токен заново НЕ создавай — существующий увидит новые активы сам.
4. Выпиши, каких активов клиента в портфолио нет (их клиенту нужно добавить в Части А).

В ответе: ID кабинета (act_…), ID страницы, ник Instagram, ID пикселя, что назначено, чего не хватает.
```

После отчёта ученик говорит Claude Code «клиент <имя> подключён» — агент запускает
`doctor.py discover --account=act_… --write` и дописывает клиента в `clients.json`.

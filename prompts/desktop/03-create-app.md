# 03 · Приложение Meta для рекламы

Когда: приложения с Marketing API ещё нет. Одно приложение на все кабинеты — не по приложению на клиента.
Агент подставляет: `{{APP_NAME}}` (например «<Агентство> Ads»), `{{EMAIL}}`, `{{BUSINESS_NAME}}`, `{{BUSINESS_ID}}`,
`{{PRIVACY_URL}}` (страница политики конфиденциальности на сайте ученика; нет сайта — опубликованная страница
Google Docs / Notion с текстом политики).

```text
{{RULES}}

Задача — создать приложение Meta, через которое мой Claude Code будет управлять рекламой по API.

1. Открой https://developers.facebook.com/apps. Если я ещё не разработчик — «Начать» (Get Started),
   пройди регистрацию; подтверждение телефона или почты сделаю я.
2. «Создать приложение» (Create App):
   - название «{{APP_NAME}}», контактный e-mail {{EMAIL}};
   - сценарий использования (use case): «Создание рекламы и управление ею с помощью Marketing API»
     (Create & manage ads with Marketing API). Если такого нет — «Другое» (Other) → тип «Бизнес» (Business);
   - бизнес-портфолио: «{{BUSINESS_NAME}}» (ID {{BUSINESS_ID}}). Приложение должно принадлежать этому портфолио.
   Других сценариев и продуктов не добавляй. Если сценарий не добавил продукт Marketing API сам —
   добавь его в «Продукты» (Add product → Marketing API → Set up).
3. Настройки приложения → Основное (App settings → Basic):
   - URL политики конфиденциальности: {{PRIVACY_URL}};
   - категория: «Бизнес и страницы» (Business and Pages) или ближайшая;
   - сохрани изменения. App Secret не открывай и не копируй.
4. Переведи приложение в режим «Опубликовано» (App Mode: Live) переключателем вверху.
   Это нужно: объявления из приложения в режиме разработки Meta не пропускает (ошибка 1885183).
   Если Meta требует ещё что-то для публикации — выпиши, что именно, и остановись.
5. Проверка приложения → Разрешения и функции (App Review → Permissions and Features):
   выпиши уровень «Marketing API Access Tier» (у нового приложения обычно Limited). Ничего не отправляй на проверку.

В ответе: App ID, название, режим (Live/Development), уровень Marketing API Access Tier.
```

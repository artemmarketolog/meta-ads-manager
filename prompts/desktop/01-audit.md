# 01 · Снять показания (только чтение)

Когда: самый первый шаг ученика — понять, что уже есть. Ничего не меняет.
Агент подставляет: ничего (промпт универсальный).

```text
{{RULES}}

Задача — только посмотреть и выписать, ничего не менять и не создавать.

1. Открой https://business.facebook.com/settings (Настройки компании / Business settings).
   Если у меня несколько бизнес-портфолио — перечисли все: название и ID (число в адресе после business_id=).
2. Для каждого портфолио выпиши:
   - Аккаунты → Рекламные аккаунты: название, ID (act_…), чей (свой / партнёрский / запрошен);
   - Аккаунты → Страницы: название и ID;
   - Аккаунты → Аккаунты Instagram: ник и привязанная страница;
   - Аккаунты → Аккаунты WhatsApp: название и номера;
   - Источники данных → Пиксели (Наборы данных): название и ID;
   - Пользователи → Системные пользователи: имя, роль, назначенные приложения;
   - Аккаунты → Приложения: название и App ID.
3. Открой https://developers.facebook.com/apps. Если пишет, что я не разработчик, — просто сообщи об этом.
   Иначе выпиши мои приложения: название, App ID, тип, режим (Development / Live).
4. Для приложения, где подключён Marketing API (если такое есть): App Review → Permissions and Features
   (Проверка приложения → Разрешения и функции) — уровень «Marketing API Access Tier»
   (Limited / Full) и есть ли кнопка Upgrade.

Ответ — по пунктам, только названия и ID. Токены и ключи не выписывай.
```

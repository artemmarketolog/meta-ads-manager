# Как устроен доступ к Meta: портфолио, приложение, системный пользователь, токен

Справка для агента, чтобы объяснять ученику простыми словами. Порядок действий — `onboarding.md`,
клики — промпты `prompts/desktop/`.

## Четыре сущности

```
Бизнес-портфолио (business.facebook.com)          ← «папка» компании: кабинеты, страницы, Instagram, пиксели
 ├── Рекламные кабинеты: свои + партнёрские (клиенты дали доступ)
 ├── Страницы, Instagram, WhatsApp, пиксели
 ├── Приложение «<Агентство> Ads» (developers.facebook.com) ← пропуск к API; одно на все кабинеты
 └── Системный пользователь «Claude Ads»           ← робот портфолио; ему назначены приложение и активы
       └── Токен (EAA…)                           ← ключ, которым скилл ходит в Marketing API
```

| Сущность | Что это | Сколько | Где создаётся |
|---|---|---|---|
| Бизнес-портфолио | компания в Meta, владеет активами | одно (своё) | промпт 02 |
| Приложение | разрешение ходить в API от имени портфолио | одно на все кабинеты и клиентов | промпт 03 |
| Системный пользователь | «сотрудник-робот» портфолио; не человек, не выходит из аккаунта | один | промпт 04 |
| Токен | строка `EAA…`, по ней Meta узнаёт системного пользователя и приложение | один, бессрочный | промпт 04 |

**Не заводить приложение под каждого клиента.** Клиент даёт вашему портфолио партнёрский доступ (промпт 05),
вы назначаете его активы тому же системному пользователю — и тот же токен видит новый кабинет.

## Почему системный пользователь, а не личный токен

| | Токен системного пользователя | Личный токен (Graph API Explorer) |
|---|---|---|
| Срок | бессрочный («Никогда») | доступ к данным кончается каждые 90 дней |
| Смена пароля, выход из Facebook | не влияют | могут обнулить |
| Видит | только назначенные активы — меньше вреда при утечке | всё, к чему есть доступ у человека |
| Лимит пользователя (code 17) | свой | общий с вашими ручными действиями |

Graph API Explorer для выпуска токена не используем: прерванное на середине окно разрешений Facebook отклоняет
разрешения, и запись в кабинеты молча встаёт.

## Режим приложения: Live обязателен

Креатив `object_story_spec` создаёт скрытый пост страницы. Пост от приложения в режиме разработки виден только
его разработчикам, поэтому Meta не даёт сделать из него объявление (ошибка 100/1885183). Перевести приложение в Live
**до** выпуска токена (смена режима может сбросить старые токены). Для Live Meta просит URL политики конфиденциальности
и категорию.

## Уровни и лимиты Marketing API (документация Meta → Marketing API → Rate Limiting)

| | Limited (новое приложение) | Full (после Upgrade) |
|---|---|---|
| Очки кабинета (чтение 1, изменение 3) | 60 за 5 минут, блок 300 с | 9000 за 5 минут, блок 60 с |
| BUC `ads_management` в час | 300 + 40 × активных объявлений | 100000 + 40 × активных объявлений |
| Системных пользователей | 1 + 1 администратор | 10 + 1 администратор |
| Как получить | сразу при добавлении Marketing API | 500+ вызовов за 15 дней, ошибок < 15%, кнопка Upgrade (промпт 08) |

На Limited запуск из 3 объявлений (≈ 15 изменений + загрузки + проверки) может упереться в лимит. Скрипты это
переживают: на ошибке лимита останавливаются без повторов, state запуска сохранён, через 5 минут та же команда
досоздаёт недостающее. Большие запуски на Limited — частями по 2–3 группы.

Прочие лимиты, общие для всех уровней:
- бюджет группы — не больше 4 смен в час (скрипт сам держит 3);
- 1 правка одного объекта за 30 с сразу после копирования (скрипт ждёт и повторяет сам);
- общий лимит приложения (code 4) = 200 × активных пользователей в час — его едят вызовы «мимо кабинета»
  (`GET /<video_id>` по одному, `/me`, страницы). Массовые выгрузки — последовательно, без потоков, ночью.

## Где что хранится у ученика

| Что | Где |
|---|---|
| Токен и настройки | `~/.config/meta-ads-manager/meta.env` (chmod 600) |
| Клиенты: кабинет, страница, Instagram, WhatsApp, пиксель, форма | `~/.config/meta-ads-manager/clients.json` |
| State запусков и листы превью | `~/.local/share/meta-ads-manager/state/<клиент>/` |
| Лог всех write-запросов (без токенов и текстов) | `~/.local/share/meta-ads-manager/logs/meta_api_writes.log` |

Ничего из этого не попадает в репозиторий скилла (`.gitignore`), и скрипты не читают ничего за пределами этих путей.
